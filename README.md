# 土豆 List 桌面客户端

一款轻量化桌面工具，自动扫描局域网内开启网页共享的安卓设备，一键内置浏览器连接手机共享页面。

## 功能特点

- 自动扫描局域网设备
- 一键连接安卓设备
- 内置WebView浏览器
- 拟物纸张风格UI

## 运行要求

- Python 3.8+
- Windows 10/11（需要WebView2，Win10/Win11默认内置）

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行程序

```bash
python main.py
```

## 使用说明

1. 确保电脑和手机连接同一局域网WiFi
2. 手机端启动共享服务（端口9527）
3. 运行桌面客户端，点击"开始扫描"
4. 发现设备后点击"一键连接"
5. 在手机端确认授权（首次连接）
6. 即可在桌面端浏览手机共享内容

## 限制说明

1. 电脑与手机必须连接同一局域网 WiFi
2. 路由器需关闭「AP 隔离」功能
3. 手机需允许 APP 局域网网络权限
4. 手机需保持 APP 后台运行
